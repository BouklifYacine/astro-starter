## Reporter une correction vers un projet client

Le dépôt créé depuis un Template GitHub possède son propre historique. Utiliser un cherry-pick ou reporter le fichier ciblé, puis exécuter `bun run check`, `bun run test` et `bun run build` dans le projet client.
